## Why This Approach

This dual-license approach allows:

**For the Community (MIT):**
- Complete freedom to use, modify, and distribute the implementation
- Ability to build commercial products on top
- Full access to the formal proofs and specifications
- Freedom to learn and improve the system

**For the Creator (Reserved Model Rights):**
- Protection of the core computational innovation
- Ability to license the model commercially if desired
- Attribution and recognition of the original research
- Prevention of someone else patenting the fundamental approach

This is similar to how databases are sometimes licensed: the code is open source,
but the underlying model or database structure is reserved. Or how Elasticsearch
licenses components—core functionality is open, but specific commercial features
are reserved.
